# Post Production Standard

The single reference for building a Cluefolio post. If a pack ignores this file,
it does not ship.

---

## 1. The seven slides

| # | Slide | Copy limit | Image |
|---|---|---|---|
| 1 | Cover | headline ≤ 6 words, dateline | best archival photograph |
| 2 | The setup | headline ≤ 4 words, one kicker line | archival photograph |
| 3 | The mechanism | headline ≤ 4 words, one kicker line | archival photograph |
| 4 | The turn | headline ≤ 4 words (numbers work well) | archival photograph |
| 5 | The cost | headline ≤ 4 words, one kicker line | archival photograph |
| 6 | The consequence | headline ≤ 6 words, one kicker line | archival photograph |
| 7 | The follow card | headline ≤ 10 words, subline ≤ 8 words | generated, no photo |

Every slide except the last carries a photograph. No paper plates in a shipped
post. Short overlay copy only — the carousel is not a document.

Rules:

- Slide 1 must work as a standalone image, at thumbnail size, with the caption
  hidden. It is the entire post's chance.
- One accent number per post, on slide 4 or 5. Two numbers compete.
- Never repeat the cover headline on another slide.
- Slide 7 is generated by the renderer and never hand-designed.

## 2. Images

All imagery is authentic archival material in the public domain, with a credit
line. Sources that work:

- Wikimedia Commons API (search by event, filter to `Public domain` or
  `No restrictions`, width ≥ 1200 px)
- US National Archives (NARA) records
- Library of Congress Prints & Photographs
- US Navy / military historical archives

Never:

- Unmarked AI imagery of a real event.
- AI reconstructions that "look real" without a visible label.
- Copyrighted press photographs, even in a "history" context.
- Victim or crime-scene imagery.

If no authentic photograph exists, use a disclosed reconstruction with the
`disclosure` field set, and the label rendered on the slide. A disclosed
reconstruction is a design choice; an undisclosed one is a credibility risk the
account cannot afford.

## 3. Files a pack needs

```
content/<slug>/
  render-config.json     cover, interiors, cta
  assets/manifest.json   provenance, credit, licence, alt for every asset
  assets/<id>.<ext>      the originals, untouched
  images/01-cover.jpg … 07-follow.jpg
  slides.json            per-slide alt text and credit for the publisher
  post-metadata.json     status: "ready" only when publishable
```

## 4. render-config.json schema

```json
{
  "slug": "example",
  "rail": "POST 012",
  "palette": { "paper": "#F4EFE6", "ink": "#15130F",
               "muted": "#5B5348", "rule": "#B9AE9C", "accent": "#8C2F1E" },
  "cover": {
    "asset": "cover-id", "wordmark": "CLUEFOLIO", "category": "MURDER",
    "headline": ["LINE ONE", "LINE TWO"], "dateline": "City  ·  1912",
    "crop": { "fx": 0.5, "fy": 0.5, "zoom": 1.0 }
  },
  "interiors": [
    { "template": "photo", "out": "02-setup.jpg", "asset": "asset-id",
      "headline": ["SHORT", "LINE"], "kicker": "One line of context",
      "crop": { "fx": 0.5, "fy": 0.5, "zoom": 1.0 } }
  ],
  "cta": {
    "out": "07-follow.jpg",
    "headline": "Everything you were never told. Every day.",
    "sub": "Follow so you don't miss it.",
    "button": "FOLLOW @CLUEFOLIO",
    "handle": "@cluefolio",
    "footnote": "Real archival images. Sources in every caption."
  }
}
```

Templates:

- `photo` — full-bleed image, dark scrim, wordmark rail, headline, kicker.
  This is the default and the only slide type that ships.
- `plate` — paper background, optional photo band, headline/stat/body. Kept for
  archive and for disclosed reconstructions, not for shipped posts.

## 5. The follow card

Fixed layout, generated from `cta`. Copy rules:

- Headline: the promise, under 10 words. Default:
  **"Everything you were never told. Every day."**
- Subline: the reason to act now, under 8 words. Default:
  **"Follow so you don't miss it."**
- One ask, one button. Never two.

Approved rotation:

| Headline | Subline |
|---|---|
| Everything you were never told. Every day. | Follow so you don't miss it. |
| Murder, mystery, disaster — one a day. | Follow so the next one finds you. |
| You've never heard the next one. | One story a day. |

## 6. Commands

```powershell
# render every slide from render-config.json
python scripts/render_post.py --slug <slug>

# regenerate the dashboard payload (status, timeline, published links)
python scripts/build_dashboard_data.py

# validate without calling Meta
python -m automation.publish --post <number> --dry-run

# publish now
python -m automation.publish --post <number>

# republish after a fix (creates a new post; delete the old one first)
python -m automation.publish --post <number> --force
```

## 7. Status and the calendar

`status` in `post-metadata.json` / `dashboard_content.py`:

- `draft` — in production. **Can never publish automatically.**
- `ready` — passed every gate. The daily workflow will publish it on its date.
- `published` — set automatically from `automation/state/published.json`.

The daily run publishes the post whose date is today **and** whose status is
`ready`. Anything else is a clean no-op.

## 8. Dashboard

```powershell
python dashboard/serve.py        # http://127.0.0.1:8080/dashboard/
```

It reads `content/dashboard.json`, which merges the authored packs with the
publish ledger — so status, publish time, and live permalinks come from the
actual ledger, not from memory. The page re-checks the payload every 60 seconds
and re-renders only when something changed.

Rebuild after any content edit:

```powershell
python scripts/build_dashboard_data.py
```

## 9. Definition of done

A pack ships only when all of these are true:

- [ ] Seven rendered slides, 1080×1350, every one under 8 MB.
- [ ] Every slide except the last has an authentic credited photograph.
- [ ] `slides.json` has alt text for all seven.
- [ ] Caption keyword appears in the first 125 characters.
- [ ] Three to five hashtags, one location tag.
- [ ] First comment carries the source ledger.
- [ ] `status: "ready"` set only after the gates passed.
- [ ] Dry run is clean.
