# Platform Specifications

Verified against current platform documentation as of October 2026. Re-check before each campaign.

## Instagram feed

| Spec | Value |
|---|---|
| Aspect ratio | 4:5 portrait (preferred), 1:1 acceptable |
| Recommended resolution | 1080 × 1350 px |
| Max resolution | 1440 px wide |
| Formats | JPEG, PNG |
| Max file size | 8 MB |
| Carousel | Up to 20 images; we use 4–10 |
| Caption limit | 2,200 characters |
| Visible caption before "more" | ~125 characters |
| Hashtags | 3–6 specific; more is not better |
| Alt text | Supported per image; always provide |

**First-line rule:** the first ~125 characters must contain the hook and must survive truncation.

## Facebook feed

| Spec | Value |
|---|---|
| Aspect ratio | 4:5 or 1:1 |
| Recommended resolution | 1080 × 1350 px |
| Formats | JPEG, PNG |
| Max file size | 8 MB (practical) |
| Carousel | Up to 10 images |
| Caption limit | Very high, but truncation occurs around 125–250 characters in feed |
| Hashtags | 3–4 maximum; often better with none |
| Alt text | Supported; always provide |

**Facebook difference:** the feed preview shows more text than Instagram but the "See more" cut
still lands early. Write a self-contained first paragraph.

## Accessibility

- Alt text on every image, both platforms.
- No essential information conveyed only by color.
- On-image text contrast ratio ≥ 4.5:1 against its background.
- Avoid long passages of text baked into images; captions carry the story.

## Publishing checklist

- [ ] Images exported at 1080 × 1350, sRGB, JPEG q92.
- [ ] Carousel order matches `08-visual-plan.md`.
- [ ] Caption within platform limit.
- [ ] Hashtags specific and relevant.
- [ ] Alt text pasted for each image.
- [ ] Credits included in caption or first comment.
- [ ] AI disclosure included if any generated imagery is used.
- [ ] Scheduled or posted manually by a human.
